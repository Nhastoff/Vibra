# Vibra

Настольное приложение для текста, голоса и демонстрации экрана.

Скачай установщик для своей системы в [выпуске 0.1.1](https://github.com/Nhastoff/Vibra/releases/tag/v0.1.1): Windows x64 — EXE, Ubuntu/Debian x64 — DEB, macOS — DMG или ZIP отдельно для Intel и Apple Silicon. Предварительные сборки пока без подписи издателя. Linux-пакет проверен по структуре; запуск на реальном Linux ещё не проверен. macOS собирается и запускается в GitHub Actions.

Инструкции: [Windows](INSTALL-WINDOWS.md), [Linux](INSTALL-LINUX.md), [macOS](INSTALL-MACOS.md).

## Как войти

Есть два варианта:

- **Аккаунт:** попроси у друга адрес сервера лично, вставь его в Vibra и войди с логином и паролем либо зарегистрируйся. Приглашение в сообщество открывает его каналы.
- **Ссылка на звонок:** организатор открывает «Пригласить друзей → Вход по имени · ссылка на звонок», выбирает голосовой канал и отправляет ссылку лично. Друг открывает её в браузере или вставляет целиком в поле подключения Vibra, вводит имя и входит без регистрации. Гостю доступен только звонок, без переписок сообщества. Ссылку можно отозвать; её срок ограничен.

Адрес частного сервера и ссылки на звонки не нужно публиковать в Issues. В выпуске их нет. Если открылось локальное пространство, выбери «··· → Подключение → Выбрать сервер…».

## Что нового в 0.1.1

- Звонки по ссылке и имени; вход с логином и паролем сохранён.
- Очередь аудио, передача кадров пачками, буфер воспроизведения 600 мс и плавные края речи. Проверено на двух браузерных клиентах с искусственными скачками задержки 40–400 мс. Буфер повышает устойчивость и добавляет задержку разговора; длительный обрыв сети всё ещё прерывает связь.
- Разрешение микрофона запоминается для выбранного сервера после полного перезапуска. Отозвать его можно через меню «Подключение». Системные разрешения остаются под управлением ОС.
- Сборки macOS Intel и Apple Silicon с проверкой запуска приложения и SQLite.

Голос: до 4 участников. Демонстрация экрана: запрос до 4K/60 fps, фактическое качество зависит от источника, компьютера и сети. Системный звук трансляции и автоматическое обновление пока отсутствуют.

Обновление: полностью закрой Vibra и установи новую версию поверх прежней. Аккаунты и сообщения не удаляй. Контрольные суммы установщиков находятся в Assets выпуска.

`desktop-source-0.1.1.zip` — проверенный входной архив сборки, без конфигурации сервера, учётных данных и пользовательской базы. Ручной workflow `macOS installers` собирает его на macOS и добавляет проверенные установщики в выпуск.
