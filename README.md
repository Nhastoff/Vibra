# Vibra

Настольное приложение для текста, голоса и демонстрации экрана.

**[Скачать Vibra 0.1.3](https://github.com/Nhastoff/Vibra/releases/tag/v0.1.3)** — Windows x64, новый установщик и окна разрешений в стиле приложения.

Для новой установки Linux и macOS используйте DEB или DMG/ZIP из [выпуска 0.1.2](https://github.com/Nhastoff/Vibra/releases/tag/v0.1.2), затем обновите код приложения через меню до 0.1.3. Новые полные DEB и DMG 0.1.3 пока не собраны. Mac: отдельно Intel и Apple Silicon; сборки 0.1.2 проверены запуском в GitHub Actions. Linux DEB проверен по структуре, запуск на физическом Linux ещё не проверен. Установщики пока без подписи издателя; Mac-сборки без Developer ID и нотариального заверения Apple.

Инструкции: [Windows](INSTALL-WINDOWS.md), [Linux](INSTALL-LINUX.md), [macOS](INSTALL-MACOS.md).

## Обновить установленное приложение

Для версии 0.1.2 на Windows, Linux или macOS: **··· → Справка → Проверить обновления**. Нажмите «Доступно обновление», дождитесь загрузки и выберите «Перезапустить и обновить». Скачивается подписанный пакет кода около 334 КБ без повторной загрузки Electron. Перезапуск завершит звонок; аккаунты, история, адрес выбранного сервера и согласие на микрофон сохранятся. Для версии 0.1.1 и старше сначала нужен установщик с поддержкой обновлений.

Приложение проверяет подпись и целостность пакета. При неудачном старте загрузчик возвращает рабочую версию. Перед обновлением локальной базы создаётся резервная копия. Обновление самого Electron или загрузчика потребует полного пакета. Файлы `.vbr` и `vibra-update.json` вручную открывать не нужно.

## Подключиться к друзьям

- **Аккаунт:** получите у друга адрес сервера лично, вставьте его в Vibra, войдите с логином и паролем или зарегистрируйтесь. Примите приглашение в сообщество.
- **По имени:** организатор создаёт ссылку через «Пригласить друзей → Вход по имени · ссылка на звонок» и отправляет её лично. Откройте ссылку в браузере либо вставьте целиком в поле подключения Vibra, введите имя и войдите без регистрации. Гостю доступен только выбранный звонок; ссылка ограничена по сроку и отзывается организатором.

Если открылось локальное пространство: **··· → Подключение → Выбрать сервер…**. Адреса частных серверов и ссылки на звонки не публикуйте в Issues.

## Возможности 0.1.3

- Установщик Windows, собственные окна микрофона, ошибок и «О Vibra» в дизайне приложения. Системные запросы ОС и браузера сохраняют стандартное оформление.
- Лимит голосовой комнаты — 10 человек, включая гостей. Допуск и доставка синтетических аудиокадров проверены на 10 клиентах; качество десяти интернет-подключений не проверялось.
- Правый клик по участнику: личная громкость 0–200% и «Заглушить для меня». Работает у гостей по ссылке.
- До четырёх PNG/JPG/WEBP/GIF общим размером 5 МБ в текстовом сообщении: кнопкой «+», вставкой и перетаскиванием.
- Восстановление просмотра экрана и кнопка повторного подключения. Запрос до 4K/60 fps; фактическое качество зависит от источника, компьютера и сети. Системный звук трансляции пока отсутствует.
- Буфер воспроизведения голоса 600 мс и передача аудиокадров пачками для скачков задержки. Буфер добавляет задержку разговора; длительный обрыв сети всё ещё прерывает связь.

Функции общего сервера зависят от версии кода у его владельца. Микрофон разрешается отдельно для каждого сервера; отозвать согласие можно через меню «Подключение». Камера не запрашивается.

`desktop-source-0.1.3.zip` — проверенный входной архив сборки без конфигурации частного сервера, ключей, учётных данных и пользовательской базы. Контрольные суммы файлов — в Assets соответствующего выпуска.
