# Установка Vibra на Linux

Откройте [выпуск 0.1.8](https://github.com/Nhastoff/Vibra/releases/tag/v0.1.8). Полные сборки для Linux x64 (Intel/AMD):

- Ubuntu/Debian: **Vibra-0.1.8-linux-amd64.deb**. Закройте Vibra и выполните `sudo apt install ./Vibra-0.1.8-linux-amd64.deb`.
- Другие совместимые дистрибутивы: **Vibra-0.1.8-linux-x86_64.AppImage**. Разрешите запуск файла в его свойствах и откройте. Для AppImage может требоваться FUSE 2.

Контрольные суммы — SHA256SUMS-native.txt. Проверка: `sha256sum Vibra-0.1.8-linux-amd64.deb`. Linux ARM пока не выпускается. Запускайте приложение обычным пользователем с включённым sandbox.

На Wayland для выбора экрана нужен системный портал захвата. Собственная трансляция передаёт видео; системный звук на Linux пока недоступен. Просмотр чужой трансляции со звуком поддерживается.

Удаление DEB: `sudo apt remove vibra`. Профиль хранится отдельно в каталоге конфигурации Vibra пользователя.

## Обновление приложения

Для версии 0.1.2 или новее: **··· → Справка → Проверить обновления → Доступно обновление → Перезапустить и обновить**. Небольшой пакет кода подписан ключом Vibra; профиль, аккаунт и настройки сохраняются. Перезапуск завершает текущий звонок. Для обновления самого Electron или загрузчика нужен полный установщик.

Адрес сервера или приглашение получите у друга лично. Введите адрес в окно подключения либо откройте ссылку в браузере. Частные ссылки не публикуйте в Issues.

Шумоподавление работает локально. В настройках звука доступны обычный RNNoise и режим «Усиленное — речь и тишина». После разрыва сети Vibra автоматически восстанавливает соединение и голос в прежнем канале; ручной выход отменяет возврат. Возможности общего сервера зависят от установленной на нём версии.
