# Установка Vibra на Ubuntu / Debian

Подготовлен DEB для настольной системы x64 (amd64, Intel/AMD). **Это предварительная Linux-сборка: содержимое пакета проверено, установка и запуск на Linux ещё не проверены.** Для ARM, Fedora и Arch готового пакета в этом выпуске нет.

## Установка

1. Открой [Vibra 0.1.2 в Releases](https://github.com/Nhastoff/Vibra/releases/tag/v0.1.2).
2. В Assets скачай **Vibra-0.1.2-linux-amd64.deb** и SHA256SUMS.txt.
3. Открой терминал в папке со скачанными файлами.
4. Проверь архитектуру:

       uname -m

   Для этого пакета ожидается x86_64.

5. Проверь хеш:

       sha256sum Vibra-0.1.2-linux-amd64.deb

   Он должен совпасть со строкой этого файла в SHA256SUMS.txt.

6. Установи пакет:

       sudo apt install ./Vibra-0.1.2-linux-amd64.deb

   Пакетный менеджер установит необходимые системные библиотеки.

7. Открой **Vibra** из меню приложений или командой:

       vibra

8. Получи у друга адрес сервера лично, подключись к нему, зарегистрируйся и прими приглашение друга.

Для смены уже открытого пространства: **··· → Подключение → Выбрать сервер…**.

## Микрофон и трансляция

Для разговора нужен доступный системе микрофон. Для выбора экрана в Wayland требуется работающий системный портал захвата экрана, совместимый с твоим рабочим окружением. Если выбор экрана не открылся, укажи в Issue дистрибутив, версию, окружение рабочего стола и Wayland/X11.

Приложение запускай обычным пользователем. Не используй sudo vibra и не отключай sandbox Chromium.

## Обновление и удаление

Автоматических обновлений пока нет. Для новой версии закрой Vibra и установи новый DEB командой apt install с путём к нему.

Удаление приложения:

    sudo apt remove vibra

Интернет-аккаунт и история находятся на общем сервере. Локальное пространство хранится отдельно в каталоге конфигурации Vibra твоего пользователя.


В 0.1.2 можно войти в звонок без аккаунта: попроси у организатора ссылку, открой её в браузере или вставь целиком в поле подключения Vibra и введи имя. Разрешение микрофона сохраняется для выбранного сервера.


## Обновления из приложения

Для версии 0.1.1 и старше нужно один раз установить 0.1.2 поверх прежней. После этого при новом выпуске в верхней панели появится «Доступно обновление». Нажми её, дождись загрузки и выбери «Перезапустить и обновить». Звонок завершится только после твоего нажатия на перезапуск. Проверить вручную: «··· → Справка → Проверить обновления».

Обычные обновления скачивают небольшой подписанный пакет кода Vibra без всего Electron. Текущий пакет — около 320 КБ. Это пакет приложения, не побайтовая разница файлов. Аккаунты, история, настройки сервера и разрешение микрофона сохраняются. Перед обновлением локальной базы создаётся резервная копия. Повреждённый пакет не запускается; при неудачном старте загрузчик возвращает рабочую версию.

Обновление самого Electron или загрузчика требует полного пакета приложения. Файлы `.vbr` и `vibra-update.json` предназначены для механизма обновления; вручную их устанавливать не нужно.
