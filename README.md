# Vibra

Настольное приложение для общения: текстовые каналы, голос и демонстрация экрана. Установщики находятся во вкладке **[Releases](https://github.com/Nhastoff/Vibra/releases)**.

## Подключиться к друзьям

1. Установи и открой Vibra.
2. Попроси у друга адрес его сервера лично и вставь его в поле общего сервера. Вводи адрес полностью, включая указанный другом порт.
3. Нажми «Подключиться» и зарегистрируйся. Если у тебя уже есть аккаунт на этом сервере, войди с прежним никнеймом и паролем.
4. Попроси у друга приглашение и присоединись к его сообществу.
5. Для голоса открой канал «Гостиная» и разреши микрофон. Для трансляции нажми «Поделиться экраном» и выбери экран либо окно.

Если приложение уже открыло локальное пространство: **··· → Подключение → Выбрать сервер…**, затем вставь тот же адрес.

Выбирай общий сервер для связи между разными компьютерами. Локальное пространство хранит отдельные аккаунты и сообщения на одном устройстве.

## Возможности выпуска

- Аккаунты, сообщества, приглашения, роли и текстовые каналы.
- Голосовые каналы до 4 участников, отключение микрофона и проверка микрофона с прослушиванием себя.
- Демонстрация выбранного окна или экрана, включая соединение через TURN для разных сетей.
- Запрос видео до 4K / 60 кадров/с; фактическое качество зависит от источника, компьютера и сети. Внешняя проверка реле выполнена на 720p.

Системный звук трансляции и автоматическое обновление пока не реализованы. У Windows-сборки пока нет цифровой подписи.

## Проверить скачанный файл

В Assets выпуска есть SHA256SUMS.txt. Сравни хеш файла с ним; команды приведены в инструкциях.

При ошибке создай [Issue](https://github.com/Nhastoff/Vibra/issues), укажи систему и текст ошибки. Пароли, коды входа и личные сообщения прикладывать не нужно.
