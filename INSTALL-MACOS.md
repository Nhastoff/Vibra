# Установка Vibra на macOS

В [выпуске 0.1.1](https://github.com/Nhastoff/Vibra/releases/tag/v0.1.1) выбери DMG для своего процессора:

- Apple Silicon (M1, M2 и новее): файл с `mac-arm64` в имени.
- Intel: файл с `mac-x64` в имени.

Тип процессора указан в меню Apple → «Об этом Mac».

1. Открой DMG и перетащи Vibra в папку «Программы».
2. Запусти Vibra из «Программ». Предварительная сборка пока без подписи Developer ID и нотариального заверения Apple. Если macOS блокирует запуск, проверь источник и контрольную сумму файла; при желании разреши запуск именно Vibra в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Не отключай защиту всей системы.
3. Получи адрес сервера у друга лично и вставь его в Vibra. Логин и пароль работают, как раньше.
4. Для входа без регистрации организатор может прислать ссылку на звонок. Открой её в браузере либо вставь целиком в поле подключения Vibra, введи имя и нажми «Войти в звонок».
5. Разреши микрофон, когда начнёшь разговор. Vibra запоминает решение для этого сервера. У macOS есть отдельное системное разрешение на микрофон.
6. Для демонстрации экрана разреши запись экрана в системных настройках macOS и выбери окно или экран. После изменения системного разрешения может потребоваться перезапуск Vibra.

ZIP содержит ту же программу без образа диска. Сборки Intel и Apple Silicon собираются отдельно на macOS в GitHub Actions; проверяется запуск упакованной программы и локальной базы SQLite. Микрофон, динамики и реальная демонстрация на физическом Mac требуют пользовательской проверки.

Контрольные суммы macOS находятся в `SHA256SUMS-macOS.txt` выпуска. Проверка в Терминале: `shasum -a 256 /путь/к/скачанному.dmg`.

Обновление: закрой Vibra и замени приложение в «Программах». Не удаляй данные приложения. Автоматическое обновление пока отсутствует.
