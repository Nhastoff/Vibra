# Установка Vibra на Windows

Этот выпуск — для Windows x64 на Intel/AMD. Отдельной ARM-сборки пока нет.

1. Открой [Vibra 0.1.7 в Releases](https://github.com/Nhastoff/Vibra/releases/tag/v0.1.7).
2. В Assets скачай **Vibra-0.1.7-Setup-x64.exe**.
3. Запусти файл и пройди мастер установки: выбери папку и ярлык.
4. Открой Vibra через ярлык.
5. Попроси у друга адрес сервера лично, введи его полностью и нажми «Подключиться».
6. Зарегистрируйся либо войди в существующий аккаунт этого сервера. Прими приглашение друга в сообщество.

Если открылось локальное пространство, выбери **··· → Подключение → Выбрать сервер…** и вставь полученный адрес.

## Проверка файла

Открой PowerShell в папке со скачанным установщиком:

    Get-FileHash -Algorithm SHA256 -LiteralPath .\Vibra-0.1.7-Setup-x64.exe

Сравни значение Hash со строкой этого файла в SHA256SUMS.txt из того же выпуска.

Установщик пока без цифровой подписи издателя, поэтому Windows может показать предупреждение. Если защитная система блокирует файл или хеш не совпал, остановись и сообщи об этом в Issue.

## Голос и экран

Войди в «Гостиную» и разреши доступ к микрофону. Кнопка проверки микрофона в настройках позволяет услышать себя. Для трансляции нажми «Поделиться экраном» и выбери нужное окно или монитор.

Системный звук трансляции не передаётся. Качество до 4K / 60 кадров/с запрашивается автоматически и зависит от доступных ресурсов.

## Обновление и удаление

Для обычного обновления используйте кнопку в приложении, как описано ниже. Полный установщик можно запустить поверх прежней версии, предварительно закрыв Vibra.

Удаление — через «Параметры Windows → Приложения → Vibra → Удалить». Интернет-аккаунт и история находятся на общем сервере. Локальное пространство хранится отдельно в %APPDATA%\Vibra.


В 0.1.7 можно войти в звонок без аккаунта: попроси у организатора ссылку, открой её в браузере или вставь целиком в поле подключения Vibra и введи имя. Разрешение микрофона сохраняется для выбранного сервера.


## Обновления из приложения

Для версии 0.1.1 и старше нужно один раз установить 0.1.7 поверх прежней. Для уже установленной 0.1.2 используйте кнопку обновления. После этого при новом выпуске в верхней панели появится «Доступно обновление». Нажми её, дождись загрузки и выбери «Перезапустить и обновить». Звонок завершится только после твоего нажатия на перезапуск. Проверить вручную: «··· → Справка → Проверить обновления».

Обычные обновления скачивают небольшой подписанный пакет кода Vibra без всего Electron. Текущий пакет — менее 1 МБ. Это пакет приложения, не побайтовая разница файлов. Аккаунты, история, настройки сервера и разрешение микрофона сохраняются. Перед обновлением локальной базы создаётся резервная копия. Повреждённый пакет не запускается; при неудачном старте загрузчик возвращает рабочую версию.

Обновление самого Electron или загрузчика требует полного пакета приложения. Файлы `.vbr` и `vibra-update.json` предназначены для механизма обновления; вручную их устанавливать не нужно.


## Шумоподавление и сигналы 0.1.7

Настройки → Голос и звук: Выключено / Стандартное / Нейросетевое (RNNoise). Кнопка «Проверить микрофон» воспроизводит выбранную обработку локально, без передачи в звонок. Рекомендуются наушники. У гостя по ссылке эти настройки находятся в разделе «Микрофон и шумоподавление». Там же можно отключить звуки входа и выхода. Для общего сервера требуется обновлённый серверный код; гостю достаточно обновить страницу.


## Пинг и звук трансляции

Наведите мышь на зелёную связь внизу окна или выберите её клавишей Tab. Показан последний HTTP RTT до сервера, измеряемый существующим heartbeat раз в 5 секунд. Это не полная задержка голоса между участниками. Та же подсказка есть у гостя в браузере.

Перед показом экрана выберите **Передавать звук**. Микрофон работает отдельно. Каждый зритель, включая гостя по имени, может **Включить/выключить звук трансляции** и изменить её громкость **0–100%**. Превью ведущего всегда без звука; отключение входящего звука заглушает и трансляцию.

**Браузер Chrome/Edge:** для звука выберите другую вкладку и включите передачу её звука в системном выборе. Вкладки Vibra исключаются по Capture Handle. Неподтверждённый системный/оконный захват отбрасывается, чтобы не возвращать голоса собеседникам.

**Настольная Vibra:** звук других приложений доступен в Electron 44.9.0 на Windows сборки 20348 или новее. Используется исключение звука процесса Vibra; передаётся системный звук других приложений, включая приложения вне выбранного видеоокна. Это явно показано в окне выбора. На Windows 10 сборки 19045, Linux и macOS безопасный нативный режим пока отключён с объяснением: можно передавать видео и смотреть чужие трансляции со звуком. Нативная положительная изоляция на физической Windows 11 не испытана; поддержка основана на проверенном пути исходников Electron/Chromium и политике выдачи устройства. Браузерная передача аудио проверена на сгенерированном видео и звуке между реальными WebRTC-клиентами.

Настройки зависят также от версии серверного кода. Экран и аудио не записываются. Эхоподавление микрофона не заменяет исключение звука приложения из трансляции.



## Автореконнект и статусы

После потери сети или переключения VPN браузер и настольное приложение восстанавливают соединение с сервером и возвращают голос в прежний канал. Соединение, зависшее без явного события отключения, проверяется по heartbeat. Статусы участников и списки каналов обновляются после восстановления; устаревшие ответы не подменяют свежий список.

Заглушение микрофона и настройки обработки сохраняются. Ручной выход отменяет автореконнект; удаление из канала, закрытый доступ и смена аккаунта не вызывают бесконечный повторный вход. Гостевой звонок сохраняет прежнюю гостевую сессию. Демонстрацию собственного экрана после обрыва нужно запустить заново.

Для новых возможностей нужен обновлённый сервер из исходников 0.1.7. После его обновления один раз перезагрузите открытые браузерные страницы и интерфейс приложения.
