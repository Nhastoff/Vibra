# Установка Vibra на macOS

Откройте [выпуск 0.1.8](https://github.com/Nhastoff/Vibra/releases/tag/v0.1.8). Выберите процессор в меню Apple → «Об этом Mac»:

- **Apple Silicon (M1/M2/M3/M4 и новее):** Vibra-0.1.8-mac-arm64.dmg.
- **Intel:** Vibra-0.1.8-mac-x64.dmg.

Закройте прежнюю Vibra. Откройте DMG, перетащите Vibra в Applications и запустите оттуда. В выпуске также есть ZIP для обеих архитектур. Профиль хранится отдельно в ~/Library/Application Support/Vibra.

Проверка: `shasum -a 256 Vibra-0.1.8-mac-arm64.dmg` (для Intel замените имя). Сверьте значение с SHA256SUMS-native.txt. Сборки не имеют Developer ID и нотариального заверения Apple; macOS может блокировать открытие. Подпись небольшого пакета обновления не заменяет подпись установщика Apple.

Разрешите микрофон и запись экрана только при соответствующем действии в приложении. Системный звук при собственной трансляции на macOS пока недоступен; видео и просмотр чужого экрана со звуком поддерживаются. Удаление: переместите Vibra из Applications в корзину.

## Обновление приложения

Для версии 0.1.2 или новее: **··· → Справка → Проверить обновления → Доступно обновление → Перезапустить и обновить**. Небольшой пакет кода подписан ключом Vibra; профиль, аккаунт и настройки сохраняются. Перезапуск завершает текущий звонок. Для обновления самого Electron или загрузчика нужен полный установщик.

Адрес сервера или приглашение получите у друга лично. Введите адрес в окно подключения либо откройте ссылку в браузере. Частные ссылки не публикуйте в Issues.

Шумоподавление работает локально. В настройках звука доступны обычный RNNoise и режим «Усиленное — речь и тишина». После разрыва сети Vibra автоматически восстанавливает соединение и голос в прежнем канале; ручной выход отменяет возврат. Возможности общего сервера зависят от установленной на нём версии.
