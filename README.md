# Vibra

Настольное приложение для текста, голоса и демонстрации экрана.

**[Скачать Vibra 0.1.5](https://github.com/Nhastoff/Vibra/releases/tag/v0.1.5)** — Windows x64, исправление ссылок-приглашений в чате.

Для новой установки Linux и macOS используйте DEB или DMG/ZIP из [выпуска 0.1.2](https://github.com/Nhastoff/Vibra/releases/tag/v0.1.2), затем обновите приложение через меню до 0.1.5. Новые полные DEB и DMG 0.1.5 пока не собраны. Mac: отдельно Intel и Apple Silicon; сборки 0.1.2 проверены запуском в GitHub Actions. Linux DEB проверен по структуре, запуск на физическом Linux ещё не проверен. Установщики пока без подписи издателя; Mac-сборки без Developer ID и нотариального заверения Apple.

Инструкции: [Windows](INSTALL-WINDOWS.md), [Linux](INSTALL-LINUX.md), [macOS](INSTALL-MACOS.md).

## Обновить приложение

Для версии 0.1.2 или новее на Windows, Linux или macOS: **··· → Справка → Проверить обновления** → **Доступно обновление** → **Перезапустить и обновить**. Скачивается небольшой подписанный пакет кода без повторной загрузки Electron. Перезапуск завершит звонок. Аккаунты, история, выбранный сервер, настройки и согласие на микрофон сохраняются. Для версии 0.1.1 и старше сначала нужен установщик с поддержкой обновлений.

Подпись и целостность пакета проверяются. Перед обновлением локальной базы создаётся резервная копия. При неудачном старте загрузчик возвращает рабочую версию. Обновление самого Electron или загрузчика требует полного пакета. Файлы `.vbr` и `vibra-update.json` вручную открывать не нужно.

## Шумоподавление и звуки

**Настройки → Голос и звук → Шумоподавление**:

- **Выключено** — без отдельного шумового фильтра.
- **Стандартное** — встроенное шумоподавление браузерного движка; режим по умолчанию.
- **Нейросетевое (RNNoise)** — локальная модель в WebAssembly и AudioWorklet. Аудио не отправляется внешнему сервису обработки. Модель загружается с выбранного сервера Vibra.

Эхоподавление и автоматическая регулировка усиления остаются включёнными. Режим меняется без выхода из звонка и сохраняется на устройстве. При недоступности RNNoise показывается ошибка и сохраняется предыдущий рабочий режим. Сила и качество подавления зависят от микрофона и шума.

**Проверить микрофон** позволяет услышать результат выбранного режима. Во время проверки микрофон не передаётся участникам и не записывается. Используйте наушники. Гость по ссылке открывает раздел **Микрофон и шумоподавление** прямо в звонке — там доступны те же три режима и проверка.

Короткие звуки сообщают об успешном входе, выходе и смене участников текущего канала. Отключаются переключателем **Звуки входа и выхода** в тех же настройках. Это собственные сигналы Vibra. Общая громкость и выбранное устройство вывода учитываются; при отключённом входящем звуке сигналы не играют.

RNNoise: [Xiph](https://github.com/xiph/rnnoise), WASM [Shiguredo](https://github.com/shiguredo/rnnoise-wasm), обёртка [web-noise-suppressor](https://github.com/sapphi-red/web-noise-suppressor). Лицензии и описание минимальной адаптации включены в `public/vendor/rnnoise` исходного архива.

## Исправление 0.1.5

Ссылки в текстовом чате и личных сообщениях теперь кликабельны. Нажмите приглашение, затем «Присоединиться к серверу». Приглашение текущего сервиса открывается внутри Vibra без перезагрузки страницы; вступление требует подтверждения. Старые сообщения повторно отправлять не нужно.

## Подключиться к друзьям

- **Аккаунт:** получите у друга адрес сервера лично, вставьте его в Vibra, войдите или зарегистрируйтесь. Примите приглашение в сообщество.
- **По имени:** организатор создаёт ссылку через «Пригласить друзей → Вход по имени · ссылка на звонок». Откройте полученную лично ссылку в браузере либо вставьте целиком в поле подключения Vibra, введите имя и войдите без регистрации. Гостю доступен только выбранный звонок; ссылка имеет срок действия и отзывается организатором.

Если открылось локальное пространство: **··· → Подключение → Выбрать сервер…**. Частные адреса и ссылки на звонки не публикуйте в Issues.

## Приглашения и работа в фоне

Участник сообщества может открыть **Пригласить друзей**, создать короткую ссылку вида `/i/Ab3_dE7z` и отправить её лично другу. Код состоит из 8 случайных символов. Участник видит и отзывает свои приглашения; владелец и администраторы управляют всеми. Старые приглашения продолжают работать.

Если браузер помнит гостевой вход по имени, открытие приглашения предлагает войти в существующий аккаунт либо зарегистрироваться и сохраняет приглашение. Неверный пароль не завершает гостевой звонок. После успешного входа приглашение принимается отдельной кнопкой.

Нажатие крестика в Windows скрывает окно в трей и сохраняет звонок. Нажмите птичку, чтобы вернуться; для завершения используйте **Выйти из Vibra** в её меню. На Linux окно сворачивается в панель задач, чтобы его можно было вернуть при отсутствии поддержки трея; на macOS доступно восстановление через Dock. Таймеры голосового окна продолжают работать в фоне.

Исправлены стыки аудиопакетов и границы речи после пауз. Последовательность кадров сохраняет подавленные паузы, пересчёт частоты звука сохраняет состояние между пакетами, переходы не перекрывают старый звук. Общий компрессор снижает перегрузку при одновременной речи. Это не гарантирует непрерывность при длительном обрыве сети.

Клик по голосовому каналу сразу подключает к нему. Повторный клик не переподключает, кнопка меню и правый клик не запускают вход. При отказе микрофона доступно повторное подключение.

## Другие возможности

- До 10 человек в голосовой комнате, включая гостей.
- Личная громкость 0–200% и заглушение участника по правой кнопке мыши, в том числе у гостей.
- До четырёх PNG/JPG/WEBP/GIF общим размером 5 МБ в текстовом сообщении: кнопкой «+», вставкой и перетаскиванием.
- Демонстрация экрана с восстановлением просмотра. Запрос до 4K/60 fps; результат зависит от источника, компьютера и сети. Системный звук трансляции пока отсутствует.
- Буфер голоса 600 мс и передача кадров пачками при скачках задержки. Буфер добавляет задержку; длительный обрыв сети прерывает связь.
- Установщик Windows и собственные окна разрешений в дизайне Vibra. Системные запросы ОС и браузера сохраняют стандартное оформление.

Возможности общего сервера зависят от версии его кода. Микрофон разрешается отдельно для каждого сервера; отозвать согласие можно через меню «Подключение». Камера не запрашивается.

`desktop-source-0.1.5.zip` — проверенный входной архив сборки без конфигурации частного сервера, ключей, учётных данных и пользовательской базы. Контрольные суммы — в Assets выпуска. RNNoise и переключение режимов проверены в Electron и Edge с искусственным микрофоном; качество реальной речи и запуск этого выпуска на физических Linux/macOS ещё не оценивались.
